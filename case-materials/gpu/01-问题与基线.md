# 阶段 1｜问题与基线

## 1. 原始任务

基于 FreeRDP 等 30 万行级以上开源库实现 HarmonyOS 远控应用。现有实现的视频处理走 CPU/软件路径，没有走 HarmonyOS 硬件解码与 GPU 合成，用户在远端播放视频时感知到卡顿。

本案例要做的不是“增加一个 GPU 开关”，而是把原有路径改造为一条可验证、可回退、可长时运行的硬解 + GPU 合成链路。当前仓库有某次运行的可见播放/交互素材，但尚未形成与源码 commit、decoder path 和性能采样绑定的 before/after 证据。
