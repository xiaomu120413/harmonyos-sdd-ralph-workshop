# 阶段 1｜问题与基线

## 1. 原始任务

基于 FreeRDP 等 30 万行级以上开源库实现 HarmonyOS 远控应用。用户报告远端播放视频时出现卡顿，希望评估 HarmonyOS 平台硬件解码与 GPU 合成方案。当前仓库有某次运行的可见播放/交互素材，但尚未形成与源码 commit、decoder path 和性能采样绑定的 before/after 证据。

## 2. 先分开事实与假设

| 陈述 | 当前状态 | 需要的证据 |
|---|---|---|
| 用户报告视频播放卡顿 | `USER REPORT`；before 视频未入库 | 同一片段持续录屏 |
| 当前走 CPU/软件 H.264 解码 | `UNKNOWN` | subsystem、candidate、decoder、fallback 日志 |
| CPU 解码是卡顿主因 | `UNKNOWN` | CPU/FPS、queue、分段耗时与 A/B |
| 硬解一定能解决 | `UNKNOWN` | 最小穿刺和同场景验收 |
