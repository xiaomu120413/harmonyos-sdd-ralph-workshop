# 阶段 1｜问题与基线

## 1. 原始任务

基于 FreeRDP 等 30 万行级以上开源库实现 HarmonyOS 远控应用。当前连接、输入和基础画面已经可用，但远端播放视频时出现明显卡顿，希望利用 HarmonyOS 平台硬件解码能力改善体验。

## 2. 先分开事实与假设

| 陈述 | 当前状态 | 需要的证据 |
|---|---|---|
| 视频播放卡顿 | 现象可见 | 同一片段持续录屏 |
| 当前走 CPU/软件 H.264 解码 | 待运行时确认 | subsystem、decoder、fallback 日志 |
| CPU 解码是卡顿主因 | `UNKNOWN` | CPU/FPS、queue、分段耗时与 A/B |
| 硬解一定能解决 | `UNKNOWN` | 最小穿刺和同场景验收 |
