## 0. 每个证据包都要先放身份文件

每个 `U-GPU-*` 目录先创建 `identity.txt`，至少填写：

```text
commit=
package_hash=
run_id=
device_model=
os_build=
server=
network_profile=
resolution=
clip_or_scene=
codec_negotiated=
start_time=
end_time=
collector=
```

同一个证据包里的视频、日志、CSV 和截图必须能回到这个身份文件。若中途重新构建、换设备、换片段或重连，请生成新的 `run_id`，不要混到旧包。

## 1. U-GPU-01｜CPU/软件路径 before 基线

**对应页：28、38；对应验收：S0、AC-BASELINE。**

请补充：

| 文件名 | 采集内容 | 它能证明什么 |
|---|---|---|
| `gpu-u01-before.mp4` | 同一设备、网络、分辨率和片段连续录制 20–30 秒；同时保留操作与画面 | 卡顿现象可复现，不证明根因 |
| `gpu-u01-software-path.log` | subsystem、candidate、decoder、fallback；能看到 CPU/software path 且 GPU takeover 未发生 | 当前运行确实走旧路径 |
| `gpu-u01-before-metrics.csv` | 时间戳、CPU%、FPS、frame time、queue depth/age、drop | before 量化基线 |
| `gpu-u01-identity.txt` | 按第 0 节填写 | 把三类材料绑定到同一次运行 |

采集时不要只录一个静态画面；应包含至少一次远端画面变化或输入操作。若无法直接采到 CPU/software path 日志，请保持 `CASE FACT / PENDING`，不要用高 CPU 截图代替路径证据。

## 2. U-GPU-02｜硬解一帧主链与 after

**对应页：33、38；对应验收：SP-01～04、S1～S3、AC-PATH、AC-FRAME。**

请补充：

| 文件名 | 采集内容 | 必须出现的字段 |
|---|---|---|
| `gpu-u02-after.mp4` | 与 U-GPU-01 相同设备、网络、分辨率、片段和时长 | 画面、交互、时间范围 |
| `gpu-u02-hwdecode-path.log` | capability→create→configure→start→selected | decoder name/category、candidate、consumed、owner |
| `gpu-u02-frame-trace.log` | 选择一个 frameId 做有序 trace | input/output PTS、format、stride/planes、native output、pendingFrameId、matched EndFrame、present |
| `gpu-u02-identity.txt` | 按第 0 节填写 | commit/package/runId/device/scene |

穿刺只有在“可见画面 + 硬件 decoder 身份 + 同帧 output→owner→present”同时绑定时才能通过。仅有 after 视频仍然只能标 `MEDIA FACT / UNBOUND`。

## 3. U-GPU-03｜故障注入与 original GDI 回退

**对应页：33、38；对应验收：SP-05、S3、AC-FALLBACK。**

请补充：

| 文件名 | 采集内容 |
|---|---|
| `gpu-u03-fallback.mp4` | 注入失败前、失败发生、回到旧路径后至少各保留 3–5 秒 |
| `gpu-u03-fallback.log` | failure reason、takeover/consumed 状态、owner transition、original callback、最终路径 |
| `gpu-u03-fault-injection.md` | 注入点、注入方式、预期、实际、是否恢复、清理步骤 |
| `gpu-u03-identity.txt` | 按第 0 节填写 |

优先选择“接管前可控失败”，例如 decoder 不可用或 output 不合法；不得通过删除回退代码、制造崩溃来证明回退。视频证明可用性，日志证明实际回到了 original GDI，两者不能互相替代。

## 7. 建议目录与提交前检查

```text
evidence/gpu/user-supplied/
  U-GPU-01-before/
  U-GPU-02-hwdecode-frame/
  U-GPU-03-fallback/
  U-GPU-04-performance-ab/
  U-GPU-05-lifecycle-soak/
  U-GPU-06-ralph-issue/
```

提交前逐项检查：

- 文件名与本清单一致，或在 `README.md` 写清映射；
- 所有材料均绑定 identity，时间范围能互相对应；
- 日志保留原始顺序，不只保留手工摘录；
- 删除账号、密码、设备序列号、私网地址和不必要的用户名；
- 每条结论都能指出具体视频时间、日志行或 CSV 时间窗口；
- 资料未齐的验收项继续写 `PENDING / UNKNOWN`。
