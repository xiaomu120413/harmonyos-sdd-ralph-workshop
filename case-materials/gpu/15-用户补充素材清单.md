# GPU 当前版本证据采集清单

本文只定义把当前源码快照升为工程 PASS 所需的运行证据。已有历史 Session 和媒体可作为线索或反例，但没有与当前 `commit + package_hash + run_id + device + scene` 绑定时，不能替代本清单。

## 0. 通用身份文件

每个 `U-GPU-*` 目录必须先创建 `identity.txt`：

```text
commit=
package_hash=
run_id=
device_model=
os_build=
server=
network_profile=
resolution=
clip_or_scene=
codec_negotiated=
start_time=
end_time=
collector=
```

中途重新构建、换设备、换片段、改网络或重连时必须生成新 `run_id`。视频、日志、CSV 和截图若不能回到同一身份文件，只能标记 `UNBOUND`。

## 1. U-GPU-01｜CPU/软件路径 before 基线

**对应：S0、AC-BASELINE。**

| 文件名 | 采集内容 | 判定 |
|---|---|---|
| `gpu-u01-before.mp4` | 固定设备、网络、分辨率和片段连续录制 20～30 秒，包含实际画面变化和至少一次输入 | 只证明现象 |
| `gpu-u01-software-path.log` | subsystem、candidate、decoder、fallback；GPU takeover 未发生 | 证明当前路径 |
| `gpu-u01-before-metrics.csv` | 时间戳、CPU、FPS、frame time、queue depth/age、drop | 量化基线 |
| `gpu-u01-identity.txt` | 通用身份字段 | 绑定本组材料 |

无法取得 path 日志时保持 `CASE FACT/PENDING`，不能用 CPU 截图推断 decoder 路径。

## 2. U-GPU-02｜硬解主链与 after

**对应：SP-01～04、S1～S3、AC-PATH、AC-FRAME。**

| 文件名 | 采集内容 | 必须字段 |
|---|---|---|
| `gpu-u02-after.mp4` | 与 U-GPU-01 相同场景和时长 | 画面、交互、时间范围 |
| `gpu-u02-hwdecode-path.log` | capability→create→configure→start→selected | decoder name/category、candidate、consumed、owner |
| `gpu-u02-frame-trace.log` | 选定一个 frameId 保存有序 trace | input/output PTS、format、stride/planes、native output、pendingFrameId、matched EndFrame、present |
| `gpu-u02-identity.txt` | 通用身份字段 | commit/package/runId/device/scene |

只有“可见画面 + 硬件 decoder 身份 + 同帧 output→owner→present”同时绑定才可通过。只有视频时仍为 `MEDIA FACT/UNBOUND`。

## 3. U-GPU-03｜故障注入与 original GDI 回退

**对应：SP-05、S3、AC-FALLBACK。**

| 文件名 | 采集内容 |
|---|---|
| `gpu-u03-fallback.mp4` | 注入前、失败发生、旧路径恢复后各保留 3～5 秒 |
| `gpu-u03-fallback.log` | failure reason、takeover/consumed、owner transition、original callback、最终路径 |
| `gpu-u03-fault-injection.md` | 注入点、方式、预期、实际、恢复和清理步骤 |
| `gpu-u03-identity.txt` | 通用身份字段 |

优先注入接管前可控失败，如 decoder 不可用或 output 描述不支持。禁止删除回退代码或制造崩溃。视频证明可用性，日志证明真实路径，两者不能互相替代。

## 4. U-GPU-04｜同场景性能 A/B

## 7. 目录与提交门

```text
evidence/gpu/runs/<run_id>/
├─ identity.txt
├─ U-GPU-01-before/
├─ U-GPU-02-hwdecode-frame/
├─ U-GPU-03-fallback/
├─ U-GPU-04-performance-ab/
├─ U-GPU-05-lifecycle-soak/
└─ U-GPU-06-ralph-issue/
```

提交前必须确认：

- 所有材料绑定 identity，时间范围能够对应；
- 日志保留原始顺序和原始文件，不只保存人工摘录；
- 账号、密码、设备序列号、私网地址和无关用户名已脱敏；
- 每条结论能指向视频时间、日志行或 CSV 时间窗口；
- 资料不齐的验收项继续为 `PENDING/UNKNOWN`；
- evidence 提交不混入生产代码修改。
