## 3. 第 33–37 页的讲授链

```text

   → 说清截图只能证明“画面与交互可见”
   → 硬解日志和失败回退证据没有到齐，穿刺仍是 PENDING

34 用穿刺真实结果生成新计划
   → 已证实的边界保留
   → 未证实的问题进入后续阶段

   → Plan 管顺序，Story 管行为，Worker Packet 管一次 Session
   → 每张 Story 只交付一个结果，不通过不进入下一张

36 Story 先写伪代码和验收点
   → 伪代码冻结输入、分支、成功提交和失败不提交
   → 场景、标准、证据、失败结论必须同时存在

37 汇总证据结论
   → READY / PENDING / UNKNOWN / NOT YET 分开标记
```
