```text

   → Plan 管顺序，Story 管行为，Worker Packet 管一次 Session
   → 每张 Story 只交付一个结果，不通过不进入下一张

   → Read First、RED、Allowed、Forbidden、伪代码、AC、Stop 齐全
   → docs commit → code commit → evidence ledger

   → Stop → Preserve → Locate → Falsify → Repair → Replay
   → 每轮只允许一个 probe/change，并回写 Progress Ledger
```
